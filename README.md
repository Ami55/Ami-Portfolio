# Ami Saeednia — SEO Strategist Portfolio

Vercel-ready Next.js portfolio for Ami Saeednia.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm start
```

## Deploy with GitHub and Vercel

1. Create an empty GitHub repository.
2. Push this folder to the repository.
3. In Vercel, choose **Add New → Project** and import the repository.
4. Keep **Next.js** as the framework preset and leave the build and output settings on their defaults.
5. Deploy. Future pushes to the default branch will trigger new deployments.
